# web-security26

Лабораторна робота з веб-безпеки. Реалізація REST API та CRUD HTTP-запитів на базі **Spring Boot 4.1** та **Java 25**.

* **Автор:** oleksii
* **Дата:** 15.09.2026
* **Університет:** ЧНУ (chnu.edu.websecurity26)

---

## 🛠 Технологічний стек
- **Мова програмування:** Java 25
- **Фреймворк:** Spring Boot 4.1.1 (Spring WebMvc)
- **Бібліотеки:** Lombok
- **Збірка:** Maven Wrapper (`mvnw`)

---

## 🚀 Запуск проекту
```powershell
.\mvnw.cmd spring-boot:run
```
Додаток запуститься за адресою: `http://localhost:8080`

---

## 📡 CRUD HTTP-запити (`requests.http`)

Усі запити підготовлені у файлі `requests.http` для тестування через HTTP Client в IntelliJ IDEA:

| Операція | Метод | URL | Опис |
|---|---|---|---|
| **Отримати всі** | `GET` | `/api/v1/items` | Повертає список усіх елементів |
| **Отримати за ID** | `GET` | `/api/v1/items/{id}` | Повертає елемент за його ідентифікатором |
| **Створити** | `POST` | `/api/v1/items` | Створює новий елемент (тіло JSON) |
| **Оновити** | `PUT` | `/api/v1/items` | Оновлює існуючий елемент (тіло JSON) |
| **Видалити** | `DELETE` | `/api/v1/items/{id}` | Видаляє елемент за ідентифікатором |
